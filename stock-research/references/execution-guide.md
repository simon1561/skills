# 执行辅助

本文件只帮助执行，不定义新的质量门槛；门槛以 [quality-gates.md](quality-gates.md) 为准。完整研究、多轮合并、特殊情形开始时读相关部分。

---

## 一、对齐示例

### 决策条件卡

| 项目 | 说明 |
|---|---|
| 分析目标与类型 | 核心要回答什么、属于哪类场景 |
| 分析框架与方法论 | 本次以什么视角分析 |
| 持有期及其用途 | 真实估值期限，还是跨标的可比的研究基准。多标的项目常设统一持有期只为同尺度可比，不等于每家公司都该按此期限估值 |
| 持仓背景 | 从零研究还是已持仓；已持仓多久、成本、占比 |
| 回报门槛与风险约束 | 涉及行动建议时必须确认；未确认则记为未知，输出门槛敏感性或条件建议 |

行业研究、非行动型的局部问题不强求公司行情、持仓背景或持有期。

### 后续轮次的回应方式

- 用户调整方向 → 说明如何修改框架，确认是否符合意图
- 用户补充信息 → 说明它如何影响分析，确认理解是否正确
- 模糊之处 → 主动提问澄清
- 发现视角盲区 → 提出挑战，说明会遗漏什么维度、可能导致什么误判

### 对齐重述示例

> 关键问题（已拉齐）：① … ② … ③ …
> 持有期视角：长期持有 3 年以上（用途：真实估值期限 / 跨标的可比基准）
> 持仓背景：已持仓 2 年，成本均价 X，占组合 Y%
> 回报门槛：用户确认 12% 年化 / 或：未确认，将输出门槛敏感性

## 二、场景覆盖清单

所有场景受质量门槛约束；方法卡按相关性裁剪。**交付内容是覆盖要求，不是章节标题。**

| 场景 | 特有前置输入 | 常用方法卡 | 交付重点 |
|---|---|---|---|
| 完整公司研究 | 商业机制假说（可先于取数提出，公司特定事实仍须核验）；用户不熟悉时另备业务介绍 | 归因、横向比较、估值与市场预期、情景与敏感性、基线更新、资本配置政策与治理 | 见下方覆盖基准 |
| 局部深挖 | 明确要解释的指标与期间 | 归因（核心）、横向比较 | 该指标的数据与口径；追因链；同业对比；结构性还是暂时性；证伪条件与观察窗口 |
| 多轮合并 | 各轮已有产出 | 按需 | 按分析维度组织，抹去轮次痕迹 |
| 持仓跟踪 | 上轮报告；提取核心赌注与证伪条件作基线 | 基线更新（核心）、估值与市场预期、资本配置政策与治理 | 基线来源；各证伪条件当前状态；基线后的新政策、新事件与管理层动态；论点是否成立 + 当前价格是否仍有吸引力；下一个观察节点 |
| 行业 / 板块扫描 | 统一的比较口径 | 横向比较（核心）、估值与市场预期 | 扫描范围与筛选维度；横向对比矩阵；行业共性还是公司特有；深研优先级排序；行业政策风险 |
| 催化剂 / 事件 | 事件前基线；受影响环节的待核验假说 | 归因、基线更新、情景与敏感性 | 影响假说与实际数据的对比；各维度的事实、判断与量级；管理层响应；同行横向影响；对原有逻辑的净影响（方向 + 量级）；市场反应与估计增量是否匹配；是否触发已有证伪条件 |
| 特殊情形 | 核心假设显式化 | 价值实现（核心）、横向比较、情景与敏感性 | 核心假设；现金与资产穿透；假设成立的条件（VIE、监管、管理层意愿、时间窗口）；核心假设的正反证据与替代解释；同业可比情形；持仓建议与退出条件 |

### 完整研究的覆盖基准

只适用于完整公司研究，不是局部任务的必做项。

| 组 | 覆盖内容 |
|---|---|
| 商业与竞争 | 商业模式与护城河机制；收入结构与驱动；竞争格局与份额变化 |
| 财务与资本配置 | 财务速览（口径已标注）；利润归因；现金流健康度（含经营现金流与净利分叉的解释）；资本配置与治理评价 |
| 估值、风险与决策 | 市场定价隐含假设；多空两侧与赔率；估值与综合判断。涉及行动建议时，给出条件及对称论证 |
| 证伪、跟踪与未决 | 核心赌注与证伪条件；主要失效路径；跟踪节点；未决问题 |

开头的投研摘要给出：核心论断、核心发现、估值锚、主要风险、验证节点。

## 三、交付模板

### 持仓决策依据

长期持有场景可并入报告的决策章节，也可独立成卡。这是少数允许标签式结构的输出，因为快速对照需要稳定结构。

```
1. 为什么持有（核心论断一句话）
2. 护城河机制：不是标签是机制——壁垒是什么、为什么难复制、什么条件下被侵蚀
3. 主要失效路径：哪些情形会让论断失效
4. 价格框架：各情景下的回报，以及当前价格是否仍有吸引力
5. 决策更新触发条件：信号与噪音按 methods「基线更新」的标准划分
```
