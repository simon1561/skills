# 数据获取与选源

本文件回答一个问题：某类数据需求该优先找哪类来源、用什么工具。工具为建议非强制，没列到的工具能达到效果照样用，列到的没装就走"没有时"一列。

---

## 选源原则

1. **一手优先，用户已给的材料先读**：监管申报 / 官方发布 > 二手聚合 API > 媒体转述。用户已提供的本地财报、文档、链接先用，不必另搜同一份原文；用户转来的研报、媒体文章仍属二手。
2. **按需求选源**：先确定要哪类数据，再找对应类别的源，不让手边恰好装了的工具决定拿什么数据。
3. **撞墙升级**：被反爬或动态渲染挡住时，换 jina、登录态浏览器或 computer-use 类能力读取；付费墙只用使用者已有的授权访问，不绕过。仍读不到时走替代源或披露限制，不凭记忆编造。
4. **关键数字交叉验证**：要求见 quality-gates 第三节；选源时注意二手数字回一手核，两个 API 可能转载同一数据商，不必然独立。断言"查不到"的要求见 quality-gates 第二节。搜索结果摘要（尤其聚合类工具的 AI 摘要）不直接信。
5. **效果第一，同等效果下优先低成本**：泛搜先用自带 websearch，抓正文先用免费的 fetch / jina；深度研究该上专业工具就上。

## 否决记录（2026-06 评估，适用于当时的工具环境）

- **Exa financial report 类别**：只覆盖 SEC 10-K 与 Yahoo Finance、发现式而非取原文，对 EDGAR 几乎零增量，中文不可用。
- **tavily research / exa deep 等贵端点**：贵且未必优于自编排（多次轻量搜索 + 抓正文 + 自综合）。
- **tavily extract**：与免费的 fetch / jina 重叠，仅兜底。
- **FMP**：transcript 可免费替代，free tier 限制重、配置复杂、与 EDGAR 重叠。
