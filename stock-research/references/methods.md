# 方法工具箱

按**研究问题**检索，不按纪律名称激活。用哪张卡由问题决定，不需要事前声明，也不需要向用户报批。

**方法可选，质量不可选**：选不选某个方法是判断；一旦用了，对应的质量要求自动生效，见 [quality-gates.md](quality-gates.md)。

| 你要回答的问题 | 用哪张卡 |
|---|---|
| 这个指标为什么变化 | 归因 |
| 和同业比怎么样 | 横向比较 |
| 当前价格对应什么预期 | 估值与市场预期 |
| 哪些假设会改变结论 | 情景与敏感性 |
| 这个价值能不能实现 | 价值实现 |
| 新信息是否改变原判断 | 基线更新 |
| 资本怎么配置的、制度环境有什么影响 | 资本配置、政策与治理 |
| 还要不要继续研究 | 研究优先级与停止 |

---

## 归因

用于：指标异常、问题深挖、利润变化的原因分析。

**先分解，再解释**。可加总分解须先写恒等式（收入 = 量 × 价；净利 = 收入 × 净利率），再画原因链。两者不能混为一张表——恒等式描述结果的构成，原因链解释为什么会这样。

**追因深度由问题决定**，不规定层数。参考切入维度：公司层（财报可见的直接原因）、行业层（同业数据验证）、政策与宏观层、激励层（相关方的利益诉求如何驱动这个现象）。

每一层追完问一句：**再追下一层会不会改变分析结论？** 不会就可以停。

末端给出判断：暂时性问题，还是结构性的。

常见失败：停在"宏观因素""行业周期"这类不可操作的终点。如果下一层能查、且可能改变结论，就该继续。

---

## 横向比较

用于：估值判断、相对优劣、行业扫描。

**先统一口径再比较**。不同公司的同一指标可能口径不同（是否含股权激励、是否调整、分部划分方式）。口径不一致的数字不能直接排序。

解读公司指标前，先拿到同业数据或行业均值。对比的具体数字与共性／个性判断须出现在分析里。

**行业普跌时的关键问题**：这家公司的下滑幅度与同业相比如何？区分行业因素与公司特有因素，这决定了问题是周期性还是竞争力问题。

可比公司难以获得时，显式声明"对比锚点稀薄"及其对结论的影响，不强行凑数。

## 估值与市场预期

用于：判断当前价格是否有吸引力。

**两个方向，作用不同，不要混**：

- **正向估值**：在我的假设下，它值多少
- **反向估值**：要达到某个回报，需要它做到什么

反向估值通常更有用，因为它把问题从"我猜多少"变成"需要什么条件，这些条件可信吗"。

**不可识别性**：一个股价无法唯一识别增长、利润率、折现率、终值倍数这几个未知。任何"市场已经定价了 X"只能是固定其他参数后的模型输出（见 quality-gates 第五节）。

**反共识自检**：我的判断与市场定价隐含的假设是否一致？不一致的话，差异在哪、我凭什么比市场对？一致的话，这份研究的边际价值是什么（建立跟踪基线／验证共识／发现被忽视的细节风险）？第三个问题答不上来时，换一个视角再看一遍（反转交易／成长期权／清算价值／分部估值），允许最终回到原结论。

**历史高点不是估值锚**。证明历史高点不合理很容易，证明当前价格不划算才是研究任务。跌幅大小本身不构成便宜或贵的理由。

## 情景与敏感性

用于：结论对哪些假设敏感、下行到什么程度。

**情景要与机制匹配，不机械凑三档**。事件型的二元结果（批不批、赢不输）就按二元做；连续变量才适合悲观／基准／乐观。

**单点结果不等于伪精确**——缺依据、或掩盖了结果对参数的敏感性，才是。长期估值的关键参数（增速、退出估值）须给出依据；承重结论对某参数敏感时，不能只给一个数字，须一并给出该参数变动的影响。

下行情景须写明假设的来源（如"同业均值减一个标准差""历史估值区间下限"）并算出该情形下的具体回报。

**下行情景不是价格地板**。它是条件估值，不保证不会更差。可以叫悲观情景，不要叫底线。

**下行情景是否构成否决，取决于用户的决策准则**，见 quality-gates 第五节。

**Pre-mortem / Pre-parade**：假设三到五年后失败了，最可能的具体失败机制是什么（触发条件、传导链条、终点状态）？假设大成功了，最可能的路径是什么（同样三要素）？某一侧论据确实稀薄时显式声明，不强行凑数。

## 价值实现

用于：特殊情形、净现金大于市值、清算价值、分部加总大于市值。

**先把核心假设显式化**：这类论点都依赖一个前提——"现金可以被股东拿到""清算价值能回收""私有化会发生"。先写出来，再分析它在什么条件下成立。

**现金穿透**：分辨真实流动现金、短期投资、受限资金、非现金等价资产（运营子公司账面值、权益法投资）、以及 VIE 结构下的境内外限制。给出对回收率的判断。

**时间与成本**：价值实现需要多久？期间的持有成本是什么？没有明确时间表时，不假定价值会在持有期内兑现，但也不据此断定不值得投——呈现实现机制、时间的不确定性与回报敏感性，由用户的准则判断。

这类分析最容易"标签式正确、实质错误"——例如把 API 返回的 totalCash 当作纯现金。口径核实与穿透必须实质执行。

## 基线更新

用于：持仓跟踪、事件分析、新信息到达后的判断更新。

**分三件事更新，不要合成一句**：

1. 商业论点是否仍然成立
2. 估值是否仍有吸引力
3. 相对**相关的**机会成本如何（不要求扩展成组合层面的研究）

论点没破裂不等于仍值得持有——价格可能已经过高。这是持仓跟踪最常见的盲区。

**可证伪框架**：明确 1-3 个核心赌注，每条是可观察、可证伪的命题，指定跟踪指标与观察窗口。这些赌注通常就是框架对齐时识别的关键问题经深研后的固化。

**主要失效路径**：什么情形会让整个论断失效——不是降低回报，而是证明根本判断错了。列出主要的独立失效机制，不强制数量，也不声称穷尽。

**信号与噪音**（本项的权威定义在此）：按**是否改变长期现金流、风险或估值判断**来区分，不按信息发布频率。单季的份额、库存、现金回收变化可能是结构转折最早的证据；而某些年度数据可能只是噪音。

**事件分析**：先建立事件前基线，再算增量影响。存量问题不能算作事件影响。

## 资本配置、政策与治理

用于：**资本配置与治理评价适用于所有完整研究与持仓跟踪**；政策扫描按行业的监管暴露程度调用；中国市场附加项按标的所在市场调用。

**政策扫描**：检索该行业的政策动态与已知的未来政策窗口。政策对该标的的影响判断须出现在分析里——看不到影响论述就等于没扫描，不需要单独列一份"已扫描政策清单"。

**跟踪锚点**：列出已知的关键未来节点——业绩发布、政策实施日、管理层变动、限售解禁、听证或审批窗口。这些是后续跟踪的时间标尺。

**资本配置与治理**：考察资本的几类用途（再投资、并购、分红、回购、还债）的历史效果。**按重要性选取适当的评价方式，不对每一类都强行构造历史回报率**——分红的"回报率"通常不可识别，把它算出来是伪精确。另看薪酬结构是否激励短期行为、内部人持股变动、guidance 兑现率。

**回购的实质检验**：回购金额不等于股东价值。先分解股数变动——回购、股权激励、增发各贡献多少；增发可能用于融资或并购，不等同于被薪酬抵消。净股数下降既不是回购创造价值的充分条件，也不是必要条件，还须看回购价格相对内在价值的位置。

**中国市场的附加检查项**：关联交易、定增折价、大股东质押、分拆套现、同业竞争承诺的履行情况。这些在 A 股与部分港股标的上是治理风险的主要载体。

**双重上市**：A-H 两地上市的标的须说明溢价或折价的幅度与成因，不把两地价格混用。

## 研究优先级与停止

用于：决定往哪里投研究资源、什么时候收手。

**优先级的启发式**（不要求打分，也不要做成伪精确的加权模型）：

> 对决策的影响 × 当前不确定程度 × 获得有效证据的可能性，相对于研究成本

三项里任何一项接近零，这个方向就不值得投入。影响大但完全不可知的变量，不是研究对象，而是须抬升为条件的风险。

**四种合法的停止状态**：

1. 已充分回答
2. 继续研究的边际价值有限
3. 工具或数据受限
4. 与本次问题不相关

**停止研究不等于从报告中删除**。不可预测但影响重大的变量，须保留为条件、风险或敏感性（见 quality-gates 第四节）。真正该删掉的是那些既无依据、又不影响判断的猜测——例如"创始人什么时候可能离开""五年后利率在哪"。

**可选工具**：外部反例搜索（历史上同类主张成立／不成立的案例）、概率赋值。用不用看问题需要；用了就按 quality-gates 第四节的质量要求执行。

概率的置信度按**参数与模型的验证程度**说明，不是"有没有经验基率"的二分——结构化模型在没有历史基率时仍可能有依据。
