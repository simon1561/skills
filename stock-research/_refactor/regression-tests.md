# 回归测试用例

工作文档，不属于 skill 运行时文件。用于验收 v0.8.0 重构是否在修复已知错误的同时没有丢失能力、也没有制造新的过度保守。

测试原则：

- 比较旧版与新版时固定模型、工具与材料，重复运行
- A 组用例须更换公司、数字、表述与错误位置后再测，防止只学会识别原题
- 通过标准是行为，不是文本——"提到了要对账"不算通过，"发现差额并更新了受影响数字"才算

---

## A 组：已知错误（源自 NIKE 首次分析 session）

v0.7.3 一列为**静态覆盖判断**（规则文本是否有对应触发与动作），不是实测结果，不得用于计算新版的改善率。实测基线须另行跑出。

| 编号 | 错误 | 预期行为 | v0.7.3 覆盖 |
|---|---|---|---|
| A1 | 未算就排序（"X 是最大的不确定项"，而只量化了 X 一项） | 拒绝该排序，或先把被比较项在同一尺度量化 | 能拦 |
| A2 | 分解维度不独立、会重复计算（跌幅拆成倍数压缩／盈利下滑／份额损失三块相加） | 先写恒等式，识别出份额损失是前两者的原因而非并列项 | 可能拦 |
| A3 | 用"历史高点不合理"反驳当前买入 | 指出问题被偷换，从当前价格重新计算回报 | 可能拦 |
| A4 | 采用他人的不对称口径当正常化起点（剔除退款但保留同期成本） | 识别不对称，说明该口径衡量什么，不直接外推为稳态 | 能拦 |
| A5 | 把"本次未提取到"写成"公司未披露" | 先定向检索，表述限定为"本次研究未取得" | 能拦 |
| A6 | 自定义指标未与财报调节表对账（差 0.53 亿美元） | 对账、解释差额，更新受影响的全部数字 | 能拦 |
| A7 | 旁证当直接证据（渠道商全品牌同店数据用于单一品牌动销结论） | 标明覆盖范围，结论收窄或降级为风险提示 | 可能拦 |
| A8 | 把三年后的情景价格当成今日市场预期 | 拒绝该读法；若给市场隐含读数，须注明固定了哪些参数 | 能拦 |
| A9 | 手工改写交付物中的计算结果 | 由脚本或统一数据源重算，交付值与计算输出逐项一致 | 能拦 |
| A10 | 未确认持仓背景与回报门槛，自设参数后给无条件行动建议 | 改为条件建议或给门槛敏感性，不把模型设定值当用户要求 | 可能拦（子问题拦不住） |

## B 组：不得矫枉过正（新增，测重构是否损伤正常工作）

| 编号 | 场景 | 预期行为 | 不合格表现 |
|---|---|---|---|
| B1 | 简单数据查询（"某公司当前市盈率是多少"） | 直接取数回答，但仍标明时点与口径（TTM／前瞻）；亏损时不机械给倍数 | 启动完整对齐、假说、核验流程；或反过来省掉口径标注 |
| B2 | 用户参数齐全、机会确有吸引力 | 明确支持行动 | 因"仍存在未知"而自动建议等待 |
| B3 | 用户参数缺失 | 给条件建议或敏感性 | 偷设默认偏好，或把缺参数说成"等待更优" |
| B4 | 悲观情景差、基准情景好 | 同时呈现风险与回报，由用户准则决定 | 自动否决，或反向自动看多 |
| B5 | 等待确有信息价值（财报将披露决定性数据） | 可以建议等待，并答全五问 | 无法说清等什么 |
| B6 | 没有明确的等待条件，也没有相对于立即行动的理由 | 不得以"再观察"作为建议 | 用"继续跟踪"搪塞。注意：等价格、等资金约束解除是正当的等待理由，不在此列 |
| B7 | 当前便宜、但自合理高点下跌 | 从当前价格判断 | 以跌幅替代估值 |
| B8 | 当前贵、但远低于历史高点 | 同上 | 以"已跌八成"论证便宜 |
| B9 | 合法的不对称调整（退款与成本确实归属不同期间） | 解释期间与经济状态后可用 | 机械要求收益成本同剔或同留 |
| B10 | 简单问题 | 不凑三档情景、三个假说、同业名单 | 为形式完整而强行铺开 |
| B11 | 多项旁证、无直接证据 | 形成有边界的倾向性判断 | 误称事实，或因无直接证据完全拒绝判断 |
| B12 | 关键输入被修订的长报告 | 所有相关数字、排名、建议与摘要同步更新 | 只改发现错误的那一句 |
| B13 | 持仓逻辑未破裂、但价格已过高 | 重新评价持有决策 | 以"论点没坏"替代回报分析 |
| B14 | 工具或数据受限 | 限定输出范围，完成可做部分 | 捏造，或整项停摆 |

补充四项：

| 编号 | 场景 | 预期行为 | 不合格表现 |
|---|---|---|---|
| B15 | 使用者只批准讨论方案，未发出开始指令 | 不进入完整研究；已明确授权且条件齐全时也不反复报批 | 抢跑，或在已授权后仍反复索要确认 |
| B16 | 管理层口径与财报或另一可靠来源冲突 | 解释差异来源，两侧都呈现 | 只挑支持既有结论的那一份 |
| B17 | 前轮已核验，但期间、单位或调整口径发生变化 | 重新核验 | 以"上一轮查过"为由沿用 |
| B18 | 关键变量不可预测但影响重大（如二元监管结果） | 停止无效取证，但保留为条件、风险或敏感性 | 以"不可预测"为由从报告中过滤掉 |

B5 所称"五问"在测试材料中明列：等什么证据、何时可得或复核节点定在哪、不同结果如何改变决策、等待期间的价格变化与机会成本、信息仍不明朗时如何处理。

## C 组：能力未丢失（测去重是否误删）

原 C 组只是测试计划，此处补足输入与判定。

| 编号 | 输入 | 通过条件 |
|---|---|---|
| C1a | 持仓跟踪任务，提供上一轮报告 | 提取基线证伪条件并逐条对照，而非重做完整研究 |
| C1b | 持仓跟踪任务，无上一轮报告 | 做限定范围更新，并明确声明无法评价历史论点变化 |
| C1c | 事件分析任务（如监管处罚） | 给出事件前基线与增量影响，不把存量问题算作事件影响 |
| C1d | 特殊情形任务（净现金大于市值） | 穿透现金构成，给出价值实现的条件与时间 |
| C1e | 行业扫描任务，五家公司 | 先统一比较口径再排序；排序须同尺度量化 |
| C2 | 同一处口径错误分别置于任务开头与三万 token 之后 | 两种位置均触发核验 |
| C3 | 要求引用一项财务数据 | 实时获取、标注口径与时点、一手优先 |
| C4a | 用户明确表示不熟悉该公司 | 产出可独立判断的业务介绍（是否独立成文按需） |
| C4b | 多轮研究后要求合并 | 按分析维度组织、无轮次痕迹，且重查口径与版本一致性 |
| C4c | 任意完整研究 | 报告含未决问题，且不以纪律名称作章节标题 |

## D 组：方法是否被系统性少用（专测取消激活机制的退化风险）

取消激活清单后的主要风险是：模型不再需要声明方法，干脆连该做的也省了。

测法是**配对案例**——控制事实，只改变方法的必要性。评分看遗漏是否改变答案，不看方法名称是否出现。

| 编号 | 案例 | 必须出现的行为 | 配对的简单版 |
|---|---|---|---|
| D1 | 公司利润率下降，同业也普降；问竞争力是否恶化 | 做同口径横向检查，区分行业因素与公司因素 | 只问"利润率降了多少" → 不展开横向对比 |
| D2 | 收入增长但利润下滑，材料足以拆量、价、结构、成本 | 做足以定位主因的分解 | 只问"利润降了多少" → 不强行分解 |
| D3 | 公司称回购创造价值，但净股数未降 | 检查股权激励、增发与回购价格 | 只问"回购了多少钱" → 直接答金额 |
| D4 | 指标异常且表层解释不成立 | 继续追因至能判断结构性还是暂时性 | 指标正常波动 → 不过度追因 |

每组需多次运行并变换题面。判定标准：**有必要的那一侧，遗漏方法是否导致答案错误或不完整；无必要的那一侧，是否强行铺开全套方法。**

## 评分指标

| 指标 | 说明 |
|---|---|
| 严重错误进入最终建议的比例 | A 组主指标，越低越好 |
| 无必要撤回或阻断的比例 | B 组主指标，越低越好 |
| 修订后的全篇一致性 | B12 专项 |
| 工具调用数、token、耗时 | 成本 |
| 行动建议是否满足用户参数 | 不看买入率或等待率本身 |

测试只能提供"未明显丢失能力"的证据，不能证明没有任何损失。
