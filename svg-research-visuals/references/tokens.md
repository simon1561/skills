# 令牌系统 v2 · OKLCH 推导

本文件是 v2 视觉重构的**颜色与排版源真相**。所有样图与 SVG 模板都应从这里取值。
hex 为交付值；括号内 `oklch(L C H)` 为推导坐标，用于保证感知均衡、可扩展、可审计。

> 读法：改动**不动三层架构**（基础 / 数据编码 / 认知角色），只把"手挑 hex"换成"推导令牌"，并解决 v1 的令牌语义重载。

---

## 变更摘要（相对 v1）

1. **色板在 OKLCH 里重推**：分类色锁定同一 `L / C`、只转 `H`（真正平级）；单色序列等 `L` 递进；发散标度锚定中性、两臂等亮度。
2. **拆解重载令牌**：`#c17a45` 不再身兼"分类1 + 主角 + 事实边条"。主角色 `hero` 独立成令牌；棕族收敛为**一个**强调赭 `accent`。
3. **"两种红"改为分工明确**：`风险` 从"一支颜色"重构为**一种结构模式**（浅底 + 左条 + 标题），永不作数据填充；`状态红` 只作数据标记填充。
4. **状态绿换暖**：弃用 v1 冷绿 `#5fa45a`，改**低彩度桉叶绿**，与陶土红**等亮度配对**，红绿色盲下靠蓝黄轴分离，并强制冗余编码。
5. **背景阶拉开**：`页/卡` 亮度差从约 1% 拉到约 3%，让"去描边 + 底色差 + 发丝线 + 单级投影"能分区。
6. **强调底收敛为一支**：`核心判断` 与 `结论栏` 共用一个强调底，靠**位置/角色**区分，取消 v1 "两底永不混用"的微立法。
7. **无障碍变成令牌属性**：每个填充令牌附"安全文字色 + 实测对比 + 灰度/色盲可分"标注（见下表右列）。

|---|---|---|---|
| cat-1 | `#a67a52` | 55 | 暖赭 |

| cat-4 | `#5f8296` | 232 | 灰蓝（冷锚） |
| cat-5 | `#96788a` | 330 | 灰紫（冷锚） |

> 五色感知等权，无一"往前跳"。需要 6+ 类时优先改表格/小倍图，不再加色。

### 单色赭石序列（等 L 递进，弱→强）

`#efe3d0` · `#dcc39f` · `#c8a273` · `#b5824a` · `#9c6733` · `#7f4f24`
（L ≈ 0.93 / 0.85 / 0.77 / 0.69 / 0.61 / 0.52，等距）

### 发散标度（矩阵/敏感性：锚定中性 + 两臂等亮度）

- 中性中点：`#f3ede1`（0.95 0.012 84）
- 高于基准（金臂）：`#ecdcc0` · `#ddc496` · `#cbaa6a` · `#b58f4a`
- 低于基准（陶土臂）：`#f1ddd2` · `#e6c2b1` · `#d9a48f` · `#c8886f`

> 金 vs 陶土在红绿色盲下安全；两臂逐档亮度对齐，等量偏离看起来等量。矩阵文字统一主文字色。

### 状态色（等亮度 L≈0.62 · 强制冗余）

| 令牌 | hex | oklch | 只用于 |
|---|---|---|---|
| 改善 / 正向 | `#5c9a84` | 0.62 0.075 168 | **明确**改善（桉叶绿，暖系协调、色盲可分） |
| 恶化 / 负向 | `#c76a56` | 0.62 0.11 32 | **明确**恶化（陶土红） |

> 二者亮度相等（正负视觉等重）；红绿色盲下靠蓝黄轴分离。**永远**叠加位置/形状/直接标注，颜色不得单独承担区分。普通涨跌、排名、预测、分类**一律不用**状态色——改用下方"中性方向标记"。

### 中性方向标记（新增，堵住误用状态色的根源）

普通涨跌/环比方向用 **▲▼ 炭灰（`#47433c`）+ 位置**，不着色。示例：`▲ 12%　同比`。方向标记以 **SVG 路径绘制**（非字体字形），保证跨平台一致，并与相邻文字留 ≥14px 间距。

### 参照与其他

| 角色 | hex | 用途 |
|---|---|---|
| 参照线 | `#cdc3b3` | 背景同行、辅助序列 |
| 参照点 | `#b3a998` | 被压低对象、中性阈值线 |
| 预测带 | `#f2e9da` | 预测期低对比背景带（画在数据下层） |
| 中性实际参照点 | `#6a655c` 单色实心圆 | 跨情景共用的现价等实际观测；不用黑色、菱形或描边 |

## 认知角色层 Cognitive roles

角色**完全不依赖色相**，靠边条 / 虚实描边 / 浅底 / 位置区分——保证灰度与色盲下仍可分。

| 角色 | 编码 |
|---|---|
| 事实 / 证据 | 中性边框 `#ddd3c4` + 强调赭左条 `#9c5d28` + 暖 pill `#f2e6d4` |
| 机制 / 推论 | **虚线**边框 `#c3b39a`（`stroke-dasharray:8 6`）+ 冷 pill `#e9ede6`，无实边条 |
| 核心判断 / 结论 | 共用强调底 `#f7eed6`、边 `#e6ddbd`；**核心判断**内联、**结论栏**置底全宽，靠位置区分 |
| 开放风险 / 证伪 | **风险模式**（见下），不是一支颜色 |
| 判断锚点 | 默认中浅赭石 `#d8ad7a` 配深炭字；仅闭环中心等确需强锚时用深赭 `#7a4a28` 配浅字，至多一个、小面积 |

### 风险 = 结构模式（消除"两种红"）

风险**恒为**：浅底 `#f7e9e3` + `8px` 左条 `#9a5040` + 标题 `#9a5040`。
- `#9a5040` **只**作风险左条/标题，**不得**作任何数据填充。
- `状态红 #c76a56` **只**作数据标记填充，**不得**作左条/整块底。
- 大面积风险面板可降底至 `#fbf1ee`，左条/边框不变。矩阵"下行情景"用陶土臂端色（如底 `#edd9d4`、标题 `#8f5a4d`），**不借用**风险令牌。

### 深色锚点上的文字

深赭节点 `#7a4a28` 上用 `#f6f1e8`（对比 ~6:1）。全图深色面积至多一处、小面积。

## 排版 Typography（统一字面 · 系统回退 + 可选英文子集）

- **中文、数字和中英混排**：统一使用系统栈 `"PingFang SC","Microsoft YaHei","Noto Sans CJK SC",sans-serif`。macOS 优先 PingFang；Windows/Linux 分别回退到微软雅黑或思源黑体，不承诺跨系统像素完全一致。
- **纯英文小标签**：`"Libre Franklin","Helvetica Neue",Arial,sans-serif`（OFL），只用于英文 eyebrow、章节编号等独立短标签；不得用于数字、hero 数字或中英混排正文。需要离线命中 Libre Franklin 时，由 `subset-fonts.sh` 内嵌 WOFF2 子集。
- **数字**：普通数字与 hero 大数字均随系统中文栈，启用 `tnum lnum`。hero 数字依靠字号、字重、颜色、位置和留白建立层级，不使用独立衬线字体。
- **全程无 `@import`/网络字体**。中文字体不内嵌；纯英文标签可选内嵌 Libre Franklin，因此 SVG 在不同操作系统上保持结构与层级一致，但中文字面可能随系统回退略有差异。

### 字号 · 字重阶梯（1600 画布；1040 缩 ~20–25%）

| 层级 | 字号 | 字重 | 颜色/字体 |
|---|---:|---:|---|
| 主标题 | 44 | 800 | 主文字（CJK） |
| 副标题 | 21 | 400 | 次文字 |
| 分区标题 | 28 | 800 | 强调赭 |
| 卡片标题 | 22 | 700 | 主文字 |
| 正文 | 19 | 400 | 正文 |
| 注释 | 16 | 400 | 注释 |
| pill 标签 | 16 | 600 | 强调赭 |
| hero 数字 | 46–58 | 600 | 主文字 · 系统中文无衬线栈 |

> 层级靠**字号 + 颜色 + 位置 + 留白**建立，不靠 PingFang 会被合成的 700/800 差异。所有数字默认 `font-variant-numeric: tabular-nums lining-nums`。
>
> 装饰性微标签（如迷你趋势的“近 6 季”，13–14px、`#a39c8f`）不承载关键读数，允许低于正文对比线；**凡承载读数的文字 ≥15px 且对比 ≥4.5:1**（大字 ≥3:1）。

## 抬升 · 描边 · 圆角（质感）

- **卡片默认不描边**：底色差（页 vs 卡）+ 发丝线 + **单级投影**分区。
- SVG页面级主卡的规范投影：`<filter id="ps" x="-8%" y="-12%" width="116%" height="130%"><feDropShadow dx="0" dy="8" stdDeviation="13" flood-color="#322a20" flood-opacity="0.13"/></filter>`。HTML近似值可用 `0 8px 26px rgba(50,42,32,.13)`；同一成图只使用一套主卡阴影。
- 描边只保留给**数据结构**：坐标轴、矩阵基准格双定位、必要外沿。
- 圆角按组件层级收敛：**页面级主卡 12 · 卡内次级模块 10 · 紧凑语义卡/结论栏 8 · 芯片/pill 4–6 · 矩阵格 6**。圆角表达层级，不把全部容器机械统一为同一数值。

## 刻意放松的规则（Q9：还给内容判断）

- 取消并列卡片的**精确 y 坐标表**（324/378/432…）；改为"共享基线 + 有限 8px 间距"的**节奏规则**，坐标由比例尺算。
- 圆点只表示实际观测：**系列内实际值 = 所属系列色单色实心点；跨情景共用的现价等中性实际参照 = `#6a655c` 单色实心点；预测/估算 = 虚线、预测带、区间、短竖线或文字**。不用空心、异色描边、黑色或菱形制造额外强调。
- 取消"两种强调底永不混用"，收敛为一支强调底 + 位置区分。
- 预防性禁令（紫渐变/霓虹/装饰气泡…）压缩为一句"身份护栏"，不逐条罗列。
